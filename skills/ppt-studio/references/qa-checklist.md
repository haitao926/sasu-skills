# QA Checklist

Use this before asking for final approval or exporting.

## Content QA

- The deck answers the user's actual occasion and audience.
- Every slide has one clear job.
- Every slide has a one-sentence main line recorded in `page_logic.md` or `slide_blueprint.md`.
- Claims are sourced, user-provided, or labeled as inferred.
- No unsupported exact statistics, dates, institutional claims, or names.
- The outline and final slide sequence still match the requested page count.

## Visual QA

- The chosen style system is visible across cover, agenda, and body pages.
- Typography appears intentional and legible.
- Chinese editable PPTX uses WPS-safe East Asian font declarations, not only `font.name`.
- Slide density matches the review strictness.
- No generic filler dominates the page.
- Identity anchors are present where appropriate and not overused.
- Charts/diagrams have readable labels and do not imply fake precision.

## Image QA

- Each image has a declared role: evidence, core-information-figure, visual-layer, diagram-support, or decorative-texture.
- If the user asked for a richer Roil figure or a complete core figure, the image must actually be generated by Roil.
- Evidence images must remain readable and uncompressed in the delivery PPTX.
- Core-information-figures must be readable at slide size, with no garbled labels or text-image collisions.
- For teaching/courseware decks, generated images support classroom atmosphere, material context, or reviewed core figures; exact labels and concept logic remain editable unless deliberately locked.

Run `check_slide_images.py` when final images exist:

```bash
python3 /Users/apple/.codex/skills/ppt-studio/scripts/check_slide_images.py \
  --run-dir ppt-output/runs/<RUN_ID> \
  --manifest review_manifest.json
```

The script checks that image files exist, are non-empty, have acceptable aspect ratio, and are large enough for PPT packaging.

For delivery assets, also confirm the pipeline did not silently re-encode or downsample source images before packaging.

## Review QA

Before export:

- render review HTML;
- inspect all generated pages or ask the user to approve them;
- regenerate any rejected page;
- re-run artifact validation;
- export only after approval or explicit draft-export request.

## Export QA

- PPTX exists and is non-empty.
- Default PPTX contains editable text boxes for titles/body/page numbers, not only full-slide images.
- Important user-facing text is not present only inside raster images unless the export is explicitly locked-image.
- Chinese text remains in the intended CJK font when opened in WPS/PowerPoint; if uncertain, run `scripts/patch_pptx_fonts.py` before delivery.
- The figure-text contract chosen in `page_logic.md` or `slide_blueprint.md` is preserved in the delivered deck.
- `delivery_manifest.json` points to the actual PPTX and review HTML.
- Slide count in the manifest matches the number of final images.
